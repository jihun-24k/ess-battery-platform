# 학습용 측정 이상 대응 예시 — 실제 사내 승인 절차 아님

문서 버전: learning-1

## 적용 범위

ESS MVP의 가상 장비에만 적용한다. 다변량 이상 점수는 온도 고장이나 열폭주의 확정 진단이 아니다.

## 확인 사항

- 센서 값의 유효성, 운전 조건, 주변 온도와 냉각 설비 상태를 실제 현장에서는 별도로 확인한다.
- 현재 MVP에는 주변 온도·냉각 설비 실측과 실제 고장 라벨이 없다.

## 허용된 학습 동작

가상 냉각 장비의 상태를 normal에서 boost로 변경하고 메모리 상태를 확인한다.
실제 온도 설정값, 원격 설비 명령, 자동 재가동 지시는 제공하지 않는다.

## 알림

사건 발생과 모의 조치 결과를 콘솔·JSONL로 남긴다. 실제 메신저나 이메일을 발송하지 않는다.

## 결과 해석

냉각 요청은 원본 MAT 값을 변경하지 않는다. 이후 온도 변화는 냉각의 인과 효과로 간주하지 않는다.
