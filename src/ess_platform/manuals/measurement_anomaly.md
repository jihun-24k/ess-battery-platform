# Mock ESS 대응 절차 — learning-1

실제 현장 승인 문서가 아닌 학습용 문서입니다.

- mock 이상 판단이 연속 2회 발생하면 사건을 생성한다.
- 허용 동작은 가상 냉각 상태를 normal에서 boost로 변경하는 것뿐이다.
- 문서가 없거나 비어 있으면 동작을 차단하고 모의 알림을 남긴다.
- 정상 판단 연속 3회면 기준 패턴 복귀를 기록한다. 실제 장애 복구가 아니다.
- 패턴 복귀 시 미실행·재시도 대기 명령은 취소한다.
- 자동으로 냉각 상태를 normal로 되돌리지 않는다.
- 실장비 제어, 원격 온도 설정, 자동 재가동, 실제 담당자 메시지 전송은 하지 않는다.
